# 🍺 Beer Allure Reporter

Открываешь пиво — скрипт слышит звук открытия банки и автоматически:
1. Запускает тесты через `pytest`
2. Открывает Allure-отчёт через `allure serve`

---

## Требования

- Python 3.8+
- [Allure CLI](https://allurereport.org/docs/install/) (должен быть доступен в PATH)
- Микрофон
- pytest + allure-pytest в проекте

---

## Установка

```bash
pip install sounddevice numpy
```

---

## Настройка

Открой `beer_allure.py` и в самом начале укажи два пути:

```python
# Путь к корню проекта с автотестами
AUTOTESTS_PROJECT_PATH = "~/PycharmProjects/GoldApple"

# Папка для результатов allure (относительно проекта или абсолютная)
ALLURE_RESULTS_DIR = "allure-results"
```

Путь можно писать:
- с тильдой: `~/PycharmProjects/GoldApple`
- абсолютный: `/Users/username/PycharmProjects/GoldApple`
- на Windows: `C:/projects/GoldApple`

---

## Запуск

```bash
python beer_allure.py
```

Скрипт начнёт слушать микрофон и напишет в консоль:

```
=======================================================
  🍺  Beer Allure Reporter  🍺
=======================================================

📁  Проект:   /Users/username/PycharmProjects/GoldApple
📂  Results:  allure-results

🎙️  Слушаю микрофон... Открывай пиво!
```

Открывай банку рядом с микрофоном — дальше всё само.

---

## Что происходит при срабатывании

```
открыл пиво
  └─► pytest --alluredir=allure-results --clean-alluredir -v
        └─► allure serve allure-results
              └─► браузер открывается автоматически
```

Флаг `--clean-alluredir` очищает старые результаты перед каждым прогоном — в отчёте всегда только свежие данные.

Пока тесты идут или отчёт уже открыт, повторные срабатывания от микрофона игнорируются.

## Параметры детектора звука

Находятся в начале `beer_allure.py`. Менять нужно только если скрипт не срабатывает или срабатывает на посторонние звуки.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `AMPLITUDE_THRESHOLD` | `0.15` | порог громкости (0.0–1.0). Увеличь при ложных срабатываниях |
| `LOUD_SAMPLE_RATIO` | `0.3` | доля громких семплов в чанке. Обычно не трогать |
| `HISS_RATIO_THRESHOLD` | `0.25` | доля шипящих частот в спектре. Уменьши если не ловит |
| `HISS_FREQ_LOW` | `2000` | нижняя граница диапазона шипения (Гц) |
| `HISS_FREQ_HIGH` | `8000` | верхняя граница диапазона шипения (Гц) |
| `COOLDOWN_SECONDS` | `30` | пауза между срабатываниями. Должна быть больше времени прогона |

## Отладка

Если скрипт не реагирует на звук открытия — запусти отдельный отладочный скрипт:

```bash
python beer_debug.py
```

Он покажет список микрофонов и в реальном времени выводит два значения:

```
амплитуда: 0.312  ████████████  |  hiss: 0.341  █████████████
```

**Инструкция:**
1. Запусти `beer_debug.py`
2. Посиди тихо 3–5 секунд — запомни фоновые значения
3. Открой банку прямо рядом с микрофоном
4. Нажми `Ctrl+C` — скрипт выдаст готовые значения:

```
📊  МАКСИМАЛЬНЫЕ ЗНАЧЕНИЯ ЗА СЕССИЮ:
    амплитуда (пик):  0.521
    hiss_ratio (пик): 0.412

Скопируй эти значения в beer_allure.py:

  AMPLITUDE_THRESHOLD   = 0.31
  HISS_RATIO_THRESHOLD  = 0.25
```

Вставь эти значения в `beer_allure.py` и запускай снова.

## Частые проблемы

**Скрипт не слышит звук открытия**

Порог слишком высокий. Запусти `beer_debug.py` и подбери значения как описано выше. Также убедись, что открываешь банку в 30–50 см от микрофона.

**Ложные срабатывания (открывается от других звуков)**

Увеличь `AMPLITUDE_THRESHOLD` и `HISS_RATIO_THRESHOLD` на 0.05–0.10.

**Ошибка `allure: command not found`**

Allure CLI не установлен или не добавлен в PATH. Установи по инструкции: https://allurereport.org/docs/install/

Проверь что работает:
```bash
allure --version
```

**Ошибка аудиопотока при запуске**

Микрофон занят другим приложением (Zoom, Teams, браузер и т.д.). Закрой их и запусти снова.

**На Windows скрипт зависает**

Попробуй запустить от имени администратора. Также убедись, что в настройках Windows разрешён доступ к микрофону для Python.

**`ALLURE_RESULTS_DIR` не найден**

Папка создаётся автоматически после первого прогона pytest — это нормально, предупреждение можно игнорировать.
